\begin{abstract}
A Lean~4 proof of the Riemann Hypothesis and of the Generalized Riemann Hypothesis for Dirichlet
$L$-functions has been published as machine-checked code without an accompanying paper. This
document reads that code and writes its argument in ordinary mathematical language. It states
the main definitions and the main steps, gives the proofs of the steps that carry the argument,
and refers to the Lean declaration for each step that it does not explain. Background results
that the code proves but that are known in the literature are stated without proof, with the
sources that the code names. The text is an exposition and not a second verification: the
correctness of the theorems rests on the Lean kernel alone.
\end{abstract}
